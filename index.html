Dúvidas

Perguntas frequentes

Como peço um orçamento de lona sob medida?

Informe para que vai usar a lona (cobertura, silo, piscina, carga) e as medidas aproximadas de comprimento e largura. Nossa equipe orienta o melhor material para o seu caso.

Vocês vendem lona para cobrir silo?

Sim. Trabalhamos com lonas para cobertura de silagem. Informe o tamanho do silo para calcular a quantidade necessária.
